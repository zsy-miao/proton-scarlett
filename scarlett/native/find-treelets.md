Slots 2/3 are the checked, read-only header window (space 0x5358, constants lo/hi/length and backing root SRV). Missing window or public root-constant b0 fails closed. No shader replacement or guest-address cast.

Compiler option is limited by compute stage, length and backend hash `3b1bb5613f9b7419`. Requires one native subgroup of 32 for its 32-thread workgroup. Uses the existing groupshared auto-barrier pass, BFI and floating min/max helpers, subgroup active unsigned minimum and broadcast-first. Both 64-bit MakeUniform operands are checked literal zeros. The scalar and global header reads use the existing whole-DWORD range check.

On RADV and RTX 3070, the probe checks staged and linked factories, full root-chunk equality, wrong owner/root, size, mutation and tail; only the linked fixture accesses private PSO handles. All six dispatches per GPU compare **all 8,192 bytes** after a fence. The four-leaf input (`x=0,100,2,105`) and seven-leaf input (`x=0,100,40,3,110,44,9`) start with heap-order children and unit boxes. Their exact new child pairs, inverse parent links, original subtree counts and recomputed union boxes are checked. The CPU reference enumerates subtree bipartitions; the sum of internal half-surface-areas drops from 625 to 233 and 944 to 378 respectively. Other cases exercise masked-apex counting, short scalar/global header windows and walk-limit zero. Guest header address arithmetic crosses a low-32-bit carry.

Reproduce: `SCARLETT_TEST_GPU=radv scarlett/tests/find-treelets.sh /path/to/XboxBvhBuilder.dll /path/to/matched/tool` (or `nvidia`). Use dxil-spirv patch `0011` and vkd3d patch `0019`. Scope is a privately bound, single-workgroup dispatch with at most seven leaves; multi-group propagation, deeper trees, other subgroup widths and guest command-list recording are not qualified.
