# PT_BeginPass

The sixth static utility factory call selects RVA `+b92d0` and size `0x1118` at `+20452/+2045d`. `+2056d` copies that span, `+20578` selects the UTF-16 `XDXR BeginPass` name at `+cdd00`, `+2058c` loads the utility root and `+20593` calls `+c470` for device slot `+1f0`. The matched adapter submits the original container. Creation requires the matched `ScarlettBoundedBeginPassV1` compiler capability. This is a fixture result, not evidence of a retail dispatch.

Only dispatch thread X=0 writes. Original b0 contains two 64-bit addresses, `tlasVA` and `centroidBoundsVA`, then a DWORD `partitionId`. Each box is two cached Store3s: `0x7f7fffff` three times, then `0xff7fffff` three times. The first box begins at `centroidBoundsVA`. ID `0xfffffffe` places the second box at `tlasVA+16` (and skips all header reads). Otherwise the guest loads DWORDs at `tlasVA+64/+68`, then stores at `tlasVA + zext32(84 + 28*partitionId)`. Neither load changes this branch's index. The recorder rejects wrapped slot offsets.

Both original UAV buffers must be resolved, synchronized, and physically nonaliasing. The recorder copies only the 20-byte b0, validates addresses and extents, and holds both resources through fence retirement. The private compiler resolves Load1 only in an 8-byte header window (zero bytes for global), and Store3 only in one of two 24-byte box windows. Each window contains a 64-bit guest base, byte count and DWORD-aligned byte offset from the bound resource's host base. Bounds apply to the full instruction width; failing loads return zero and failing stores write nothing. The original shader never receives a host VA in b0. `test-bvh-beginpass.cpp` checks all 192 seeded words after ordinary/global dispatches and deliberately shortened GPU store windows.
