## What the shader actually does

* b0 DWORDs [0:2] = header guest VA, [2:4] = descriptors VA, [4:6] = optional centroid VA, [6] = NumberOfElements, [7] = NumberOfAllocatedElements, [8] = Flags, [9] padding. Thread X >= NumberOfElements exits. Flags 0x10: direct array at base+64*x; otherwise read two DWORDs at base+8*x and join LE into the descriptor VA. Non-null descriptor is four x4 loads. Only masked-in records (nonzero high byte at +48) take the BLAS VA from +56. BLAS+48 holds tagged root ID (low 30 bits), +60 metadata. Node VA = BLAS + 64*(id>>3). Width-checked cached reads of 4/8/12/16 bytes fetch header, triangle, fp16/fp32 box and child data.
* Computes a lane emission count (can be zero, one, or multiple in rebraid modes), skips zero. Flags bit 0 clear: slot=X. Otherwise, first active lane does DWORD **fetch-add** (opcode 355) of the subgroup sum to `vaHeader+12`. Unsigned `old+sum > NumberOfAllocatedElements`: **fetch-sub** (367) of that same sum at that same address, rejected wave emits nothing. On success broadcast old and add each lane’s exclusive prefix. Whole wave reserves together; not increment/decrement of one per invocation. Both return *prior* values; the sub result flows through a phi but not into a successful output address. No extra memory barrier in guest IR.
* u0 raw node output (128-byte stride). Writes fields at +0..111; normally input id, zero, metadata at +112/116/120; bit 1 set only +120 in this tail. Last word untouched. u1 (24 bytes) holds min.xyz, max.xyz. Bit 1 suppresses box/score/bounds in the single-record path. With scores enabled (bit 7 clear), u2 stride 8 holds a sortable high DWORD key and low input id on the single-record path. One/gather/split paths are in original DXIL; no reconstructed CPU kernel.
* Wave fmin for minima and fmax for maxima, elected lane to header+16..36 (AABB), plus centroid+0..20 when non-null (AABB midpoint). Existing bounded float min/max path is reused. The integers and floats share the private atomic UAV, not the read-only window. DWORD add/sub are device-scope relaxed atomics. An invalid read zeroes the **whole** access. Invalid float atomic suppressed. A rejected integer reservation must not return zero (would allocate slot 0); helper returns `~amount`, so guest unsigned end is UINT_MAX and a valid finite capacity rejects; same invalid-address rollback has no effect.

`tests/load-pass.sh` exercises both equal-length roots and checks eight fenced cases on the actual adapter-created PSO.

## Boundary

Factory acceptance only. A production recorder must prove ownership, lifetimes, extents/permissions for the entire reachable read set and both atomic records; prove output capacities (including the raw node 32-bit offset), alignment, no counter wrap under concurrently outstanding reservations, and limited capacity well below UINT_MAX. The original unsigned capacity check alone does not prove safe native root-UAV access. The six-private-DWORD ABI represents one contiguous read and one atomic window; do not widen these across unrelated allocations. Multiple unrelated BLAS/header/centroid owners need a checked binding design or a rejection. Fenced cases cover finite floats, one active wave, triangle and two-child box; no claim for NaN/denormal/signed-zero identity, multi-wave contention or multiple outputs per lane.
